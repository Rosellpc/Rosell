## Una base para la gestión de negocio

Una API que reúne la gestión de clientes, planes y transacciones. La interfaz administrativa en Streamlit permite trabajar con esta información y consultar un dashboard analítico.

## Autenticación y permisos

El proyecto incorpora autenticación JWT, refresh tokens rotatorios y control de acceso basado en roles y permisos (RBAC).

## Componentes del proyecto

- **API en FastAPI:** lógica de gestión de clientes, planes y transacciones.
- **Autenticación:** acceso mediante tokens y renovación de sesión.
- **Autorización:** roles y permisos para organizar el acceso.
- **Interfaz en Streamlit:** administración y visualización analítica.

## Tecnologías

Python, FastAPI, Streamlit y AWS forman parte del stack presentado para este proyecto.
